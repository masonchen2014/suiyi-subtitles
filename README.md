# 随译 · Suiyi

**免费双语字幕插件。自带 API Key，自由选模型，视频轻松看懂。**

Suiyi is a free, bring-your-own-key browser extension for bilingual video subtitles.

随译不收会员费，不需要注册随译账号。你只需准备模型服务商的 API Key，就可以在支持的视频网站上显示双语字幕。也可以连接本机模型服务。

> **插件免费 ≠ 所有模型免费。** 模型用量直接由你选择的服务商计费，免费额度以服务商为准。

## 能做什么

- **双语字幕**：同时显示原文与译文，支持中文、英语、日语等目标语言。
- **上下文翻译、短字幕显示**：有完整时间轴时先结合前后片段翻译，避免把 “the power of …” 单独翻成残句；画面只按播放进度显示短字幕，不提前铺出整段译文。
- **提前准备**：课程播放时预翻译未来约 30 秒内、最多 5 个句子，最多并发 2 个请求。
- **自由拖动**：按住字幕框拖动；双击恢复默认位置。按网站记住位置，并随播放器尺寸变化调整边界。
- **模型自由切换**：支持 OpenAI 兼容接口、Claude、Gemini，以及通义翻译专用接口。
- **本地缓存**：同样的字幕、接口、模型和语言复用译文，减少回看时的重复调用。
- **可见状态**：播放器右上角显示随译是否开启、配置是否有问题；点击可打开设置。
- **页内功能弹窗**：点击视频上的随译按钮，直接查看当前字幕、切换字幕开关和浏览观看记录。
- **字幕资料库**：记录实际播放过的视频，保存网站提供的原文字幕及已生成译文；完整/部分明确区分，支持复制和导出。
- **供 AI 读取**：导出 JSON + 本地只读 MCP 工具；另有默认关闭、独立密钥控制的 localhost 网页只读接口。

## 支持的网站

| 网站 | 当前能力 | 使用说明 |
| --- | --- | --- |
| YouTube | 标准字幕轨道优先；无法取得时间轴时读取当前字幕 | 在播放器中开启 CC，并选好原文字幕 |
| DeepLearning.AI | 读取当前课节已提供的带时间轴字幕、整句翻译与预加载 | 打开你有权访问的课程视频，通常无需展开 Transcript |

**当前不含**无字幕视频的语音识别、配音、移动端适配。能否前瞻取决于是否读到完整字幕时间轴；只有实时文字时无法提前读取后文。译文短片段按句内进度估算切换，不承诺逐词精确对齐。网站改版也可能需要调整适配。

## 安装：下载后即可加载

目前以解压扩展方式安装，尚未发布到扩展商店。**使用插件不需要 Node.js，也不需要运行服务器。**

1. 在本仓库点击 **Code → Download ZIP**，下载并解压。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启右上角的 **开发者模式**。
4. 点击 **加载未打包的扩展程序 / 加载已解压的扩展程序**。
5. 选择解压后的 **`extension` 文件夹**，不要选择仓库最外层。
6. 打开浏览器右上角的拼图菜单，找到并固定 **随译**。

## 第一次使用

1. 点击随译图标，选择模型服务商。
2. 填入该服务商的 **API Key** 和正确的 **模型 ID**，选择目标语言。
3. 点击 **测试并开启字幕**。测试会产生少量模型用量，成功后自动保存并开启。
4. 首次使用接口时，允许访问你所选的服务商域名。
5. 返回视频页面，首次安装后刷新一次，再播放视频。

没有 Key 时，可以选择 **只显示原字幕**，检查网站字幕是否能读取。

### 自定义模型服务

选择 **自定义服务 / 其他厂商**，展开接口设置，填写：

| 配置 | 说明 |
| --- | --- |
| 接口协议 | 通常选 OpenAI 兼容 · Chat Completions |
| API Base URL | 使用服务商文档中的根地址，例如 `https://your-provider.example/v1` |
| 模型 ID | 使用服务商实际提供的模型名或部署 ID，可自由填写 |
| API Key | 必须属于所填服务商及对应地域 / 业务空间 |

OpenAI 兼容地址无需手动追加 `/chat/completions`。云端接口使用 HTTPS；HTTP 仅支持本机地址。

**兼容接口不是指定 OpenAI 厂商。** 通义、DeepSeek，以及提供该协议的其他厂商或网关，都可以通过同一调用方式接入。不兼容以上协议、需要特殊云平台签名或其他鉴权方式的服务，需要新增适配。

### 本地模型

选择 **本地模型（Ollama / LM Studio）**，填写已启动服务的 OpenAI 兼容地址和已安装模型 ID。以 Ollama 为例，地址通常是 `http://localhost:11434/v1`。本机服务允许免 API Key，但需要你自己的电脑提供算力。

## 使用技巧

- **移动字幕**：鼠标按住字幕框拖动，松开后自动保存位置。
- **恢复位置**：双击字幕框。
- **更换模型**：切换服务商并保存；各服务商已保存的配置分别保留。
- **更新插件**：更新本地文件后，在扩展管理页点击随译卡片上的重新加载图标，再刷新视频页。设置页也会显示实际加载版本，并在检测到本地新版时提供更新入口。
- **没有译文**：先看右上角随译状态；确认已测试并开启、目标语言正确，以及当前网站确有字幕。

## 费用与隐私

- 随译没有中转翻译服务器，字幕直接发送到你配置的模型接口。
- API Key、服务商配置、翻译缓存、字幕位置及少量运行状态保存在本机扩展存储中，不上传到随译服务器。
- 观看记录和字幕资料保存在扩展自己的 IndexedDB 中。只记录实际开始播放的视频，可暂停记录、删除单条或导出备份；历史功能上线前的视频不会自动补录。
- 原文完整不代表译文完整：资料库不会为了补齐译文自动付费翻译整部视频。导出文件包含观看信息，只应交给你信任的 AI。
- 密钥仅在可信扩展上下文读取，不提供给视频网站的页面脚本。
- 本机存储不等于加密保险箱；请妥善保护设备，并在服务商侧设置适合自己的额度限制。
- 安装时声明视频网站及默认百炼接口权限；其他模型接口在你保存或测试时按主机申请可选权限。
- 改模型、改接口、改目标语言或改字幕合并结果，可能需要重新翻译；清理浏览器数据或重装扩展也可能清掉缓存。

## 让 AI 总结看过的视频

视频上点击随译 → **字幕资料库 / AI 接口**。可以直接复制单视频 Markdown 给 AI，或导出 `suiyi-library.json` 后连接本地 MCP：

```bash
node tools/mcp-server.mjs --library /absolute/path/suiyi-library.json
```

MCP 提供视频列表、完整/部分字幕读取和关键词检索；读取的是你导出的快照。想实时接入本机网页，可手动开启密钥保护的 Chrome 消息接口。详细数据格式、权限和客户端示例见 [AI 接口指南](docs/api.md)。

## 开发与测试

运行时是原生 Manifest V3 扩展，不需要构建步骤。开发测试需要 Node.js 20+。

```bash
npm install
npm run check
npm test
```

浏览器测试需要本机安装 Google Chrome，测试使用独立、临时的无头浏览器，不使用个人 profile：

```bash
npm run test:browser
```

`test:browser` 覆盖设置页、拖动与位置记忆、慢响应预翻译、课节切换，以及真正加载扩展后的脚本注入和后台通信。模型接口使用模拟响应，不需要真实 Key。扩展端到端测试通过私有调试管道加载临时扩展，不开放调试端口。

可选的 `npm run test:live` 访问公开课程页检查网站结构，翻译仍使用模拟响应；它可能受到网站和网络环境变化影响。

### 代码结构

```text
extension/
  manifest.json    扩展入口与权限
  captions.js      通用时间轴、句子边界、短字幕显示规则
  adapters.js      标准播放器通路、统一 frame 与站点差异注册
  content.js       播放同步、预翻译队列、字幕显示与拖动
  models.js        统一模型配置、请求构造、响应解析
  background.js    模型调度、权限检查、缓存与设置通信
  popup.*         设置界面
  panel.js        共用页内功能弹窗
  library-*       本地资料库、数据格式、访问接口与页面
  update.*        本地更新入口
tests/            核心测试、模拟网站及扩展端到端测试
tools/            本地只读 MCP 与浏览器接口客户端
```

模型层统一契约为 `SuiyiModels.translate(config, text) → Promise<string>`。新增兼容厂商只需改配置；新增协议扩展模型层即可，网站适配无需修改。详见 [模型层说明](docs/models.txt)。

网站扩展优先复用标准 HTML5 能力，只有页面或数据入口不同才注册站点差异；断句、翻译、预加载、缓存和 UI 不按网站复制。详见 [可扩展设计](docs/architecture.md)。
